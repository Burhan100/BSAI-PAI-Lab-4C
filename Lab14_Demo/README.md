# Lab 14 - Project Demo Submission

## Instructions

This lab requires you to submit a **video demo** of your project from Lab 13.

## What to record in your video:

1. Open the terminal and run: `python app.py`
2. Open browser and go to: `http://127.0.0.1:5000`
3. Type some text in the input box (positive, negative, and neutral examples)
4. Show the sentiment result for each
5. Briefly explain what the app does

## Example texts to show in video:

- Positive: "I love this university, the teachers are amazing!"
- Negative: "This was a very bad and boring experience."
- Neutral: "The class is on Monday."

## How to record:
- Use OBS Studio (free) or any screen recorder
- Keep video between 2-5 minutes
- Submit as MP4 format

## Project: NLP Sentiment Analyzer
- Backend: Flask (Python)
- NLP Library: TextBlob
- Frontend: HTML/CSS
